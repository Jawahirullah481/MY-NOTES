Quick Guide to Create Good Looking Bootstrap Form :
==============================================

📐 2️⃣ Page Layout Using Container + Grid

Bootstrap layout rule:

- Everything goes inside .container (Not always)
- Rows inside container
- Columns inside rows

<div class="container mt-5">
  <div class="row justify-content-center">
    <div class="col-md-6">
      <!-- Form goes here -->
    </div>
  </div>
</div>


col-md-6 means:

👉 On medium and larger screens, form width = 50%

------

❓When not to use container ?

- Container will always add extra padding in the horizontal direction.
- If you don't want such space (eg, gmail, github have not space at left and right), then use container-fluid or don't use anything.
- For blogs and such pages, you can wrap inside container class.

------

🧱 3️⃣ Card + Shadow (To Separate the Form)

To show the form in a separate box with shadow:

<div class="card shadow-lg p-4">
  <!-- form here -->
</div>


Bootstrap shadow classes:

shadow-sm → small
shadow → normal
shadow-lg → large

---

📝 4️⃣ Form Structure

Bootstrap form rule:

- Every input must be wrapped in .mb-3
- Order: Label → Input → Help text

<form>
  <div class="mb-3">
    <label class="form-label">Email</label>
    <input type="email" class="form-control">
  </div>

  <div class="mb-3">
    <label class="form-label">Password</label>
    <input type="password" class="form-control">
  </div>
</form>


---

🔘 5️⃣ Bootstrap Button

<button type="submit" class="btn btn-primary w-100">
  Submit
</button>


w-100 → Full width button

---

✅ 6️⃣ FINAL COMPLETE PAGE

Copy-paste this. This is production-quality Bootstrap form UI 👇

---

🧠 What You Actually Learned (Real-World)

Requirement → Bootstrap class

Centered form → row justify-content-center
Half width → col-md-6
Separate box → card
Shadow → shadow-lg
Input styling → form-control
Spacing → mb-3
Button → btn btn-primary

🅱️ Bootstrap Data Table — Quick Notes (Card Style)

We usually don’t place a table directly on the page.
We wrap it inside a Card so it looks like a separate component.

<div class="card shadow">


card → creates a box
shadow → gives elevation (separates from background)

---

🧱 1️⃣ Card Header (Title Bar)

<div class="card-header bg-primary text-white">
  User List
</div>


Class → Meaning

card-header → Top section of card
bg-primary → Blue background
text-white → White text

This becomes the title bar of the table.

---

📦 2️⃣ Card Body (Table Container)

<div class="card-body p-0">


card-body → Content area
p-0 → Removes padding so table touches edges (clean look)

---

📊 3️⃣ Table Base

<table class="table table-striped table-hover m-0">


Class → Purpose

table → Bootstrap table styling
table-striped → Alternate row colors
table-hover → Row highlight on hover
m-0 → Removes margin so it fits card perfectly

---

🧭 4️⃣ Table Head

<thead class="table-light">
  <tr>
    <th>#</th>
    <th>Name</th>
    <th>Email</th>
    <th>Role</th>
  </tr>
</thead>


table-light → Light gray header background

Makes column titles stand out

<th> is used for column headers.

---

📋 5️⃣ Table Body (Data Rows)

<tbody>
  <tr>
    <td>1</td>
    <td>Jawahir</td>
    <td>jawahir@gmail.com</td>
    <td>Admin</td>
  </tr>
</tbody>


Tag → Meaning

tr → One row
td → One cell

---

🧠 How This Looks in UI

This structure creates:

+---------------------------+
|   User List (Blue)   |
+---------------------------+
| # | Name | Email |
| 1 | Jawahir | ...      |
| 2 | Vijay      | ...      |
+----------------------------+


With shadow + hover + striping.
