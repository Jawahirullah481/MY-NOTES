# 📦 Tomcat WAR Deployment (Linux / WSL / Windows)

## 🔹 1. Install Apache Tomcat

📌 *Note:* Latest Java (Spring Boot 3+) requires Tomcat 10+

### Steps:

i) Download Tomcat

wget https://dlcdn.apache.org/tomcat/tomcat-10/v10.1.54/bin/apache-tomcat-10.1.54.tar.gz


ii) Extract and Rename

tar -xvzf apache-tomcat-10.1.54.tar.gz
mv apache-tomcat-10.1.54 tomcat


---

## 🔹 2. Generate WAR File (Spring Boot)

📌 *Important Configuration (pom.xml)*

* <packaging>war</packaging>
* Embedded Tomcat dependency → <scope>provided</scope>

### Steps:

i) Build project using Maven

mvn clean package


ii) Output

target/studentapi.war


---

## 🔹 3. Deploy WAR in Tomcat

### Steps:

i) Navigate to Tomcat webapps folder

cd ~/tomcat/webapps/


ii) Copy WAR file

cp /mnt/d/Users/Jawahirullah/Projects/Eclipse\ Projects/Student\ API/studentapi/target/studentapi.war ~/tomcat/webapps/


iii) Start Tomcat

cd ../bin/
./startup.sh


---

## 🔹 4. Verify Deployment

i) Check logs

tail -f ../logs/catalina.out


ii) Look for message

Deployment of web application archive has finished


---

## 🔹 5. Access Application

🌐 URL Format:

http://localhost:8080/<war-name>/<endpoint>


✅ Example:

http://localhost:8080/studentapi/api/student/list

---

## ⚠️ Common Issues

❌ 404 Error
→ WAR not deployed OR wrong URL

❌ No “Mapped” logs
→ Spring Boot not started

❌ Compatibility issue
→ Spring Boot 3 → Requires Tomcat 10+
