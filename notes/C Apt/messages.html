Pre and Post Increment Operators in C and Java :
=========================================

The first point to note is when the variable get updated when used with pre and post increment operators.

The Answer is : "The variable's value gets updated immediately once the pre increment and post increment expression get completed. It will not wait for the whole expression to complete to update the variable."

Example :
========
int a = 1;
int b = a++ + a; // a++ ---> 1st sub exp, a -> 2nd sub exp

Here, the value of a get incremented immediately after a++ is completed. Hence, when it reaches + a(2nd sub exp), the value of a gets incremented to 2. Hence the output of the above example is "1 + 2 = 3".



Diff Between Pre and Post Increment Operations in C and Java :
===================================================

1. Post increment Operator works similarly in java and c. There is no difference. Whenever we are using it, it first assign the value it holds to the expression and then gets updated.

2. But, the Pre increment operators works differently in both languages.

Java :
=====
The variable gets incremented first and give the updated value to the expression.

C :
==
The variable gets incremented first and doesn't give updated value to the expression. It waits for all the pre and post expressions happening in the expression. And gives the last(latest) updated value of that variable to the expression.


Example :
=========
Java :
---------
int a = 1;
int b = ++a + a++;
sout(b); // output : 2 + 2 = 4

int a = 1;
int b = ++a + a++;
printf("%d", b); // output : 3 + 2 = 5


What's happening and how the value are calculated ?
===========================================

Java :
1. ++a -> increment itself first and assign the incremented value to the expression. so, after this sub exp, 'a value is 2' and value assigned to exp is '2'.

2. a++ -> Assign the value to the expression and then increment itself. so, first assign '2' to expression and then update itself and a value becomes 3.

So, expression will be evaluated based on its assignments.
Hence, 2 + 2 = 4.

C :
1. ++a -> increment itself first and doesn't assign the incremented value immediately. it waits for whole sub exp to be evaluated to put the latest 'a' value. So, 'a' is updated to 2. But nothing assigned to expression.

2. a++ -> Similar to java, it assign value to expression, it currently have 2. so 2 will be assigned to expression and a is getting updated to 3.

3. Here is the important point : only 2nd sub exp assign the value to expression. not 1st sub exp. now all the sub expressions got completed. now 1st exp assign latest updated value to the expression(Which is value 3).

4. Now expression will evaluate. 3 + 2 = 5.



NOTE :
=======

When more than 2 subexpressions are there, first 2 sub exp gets evaluated and then result will be evaluated to 3rd sub expression and so on.

Example :
========
int a = 1;
int b = ++a + a++ + ++a; // (++a + a++) + ++a

1. Basics of Pointers in C :
------------------------------------

In C, a pointer is a variable that stores the memory address of another variable. Understanding the basic concepts of pointers is fundamental to working with them. Here's an explanation of the key components


1.1 Definition and Declaration of a Pointer :

Declaration of a Pointer

Syntax:
data_type *pointer_name;

Example:
int *ptr; // ptr is a pointer to an integer

Here, ptr is a pointer to an integer, which means it can hold the address of an integer variable.


1.2. Initializing a Pointer

To initialize a pointer, you assign it the address of a variable using the address-of operator &.

Syntax :

pointer_name = &variable_name;

Example :

int var = 10; // A regular integer variable
int *ptr; // Pointer to integer
ptr = &var; // Pointer ptr now holds the address of var


1.3. Dereferencing a Pointer :

Dereferencing a pointer means accessing the value stored at the memory address the pointer is pointing to. You use the * operator to dereference a pointer.

Syntax:

*pointer_name

Example:

int var = 10;
int *ptr = &var; // Pointer points to var
printf("%d", *ptr); // Dereferencing ptr gives the value of var, which is 10


1.4. Example: Basic Pointer Operation

#include <stdio.h>

int main() {
int var = 10; // A regular integer variable
 int *ptr = &var; // Pointer points to the address of var

printf("Address of var: %p\n", (void*)&var); // Printing the address of var
printf("Value of ptr: %p\n", (void*)ptr); // Printing the value of pointer ptr (address of var)
printf("Value pointed by ptr: %d\n", *ptr); // Dereferencing ptr to get the value at that address (value of var)

return 0;
}

Output:

Address of var: 0x7ffcaadf5b9c // Example address, will vary
Value of ptr: 0x7ffcaadf5b9c // Same as the address of var
Value pointed by ptr: 10 // Dereferencing ptr gives 10 (value of var)

2. Pointer Arithmetic in C :
-----------------------------------

Pointer arithmetic allows you to perform operations on pointers, which helps in navigating through memory and manipulating data in arrays and structures. It’s a powerful feature of C programming, enabling more flexible handling of memory locations.


2.1. Increment and Decrement Operators (ptr++, ptr--) :

Increment (ptr++): This operation moves the pointer to the next memory location, based on the data type the pointer is pointing to.
Decrement (ptr--): This operation moves the pointer to the previous memory location.

The pointer arithmetic takes into account the size of the data type being pointed to. For example, if a pointer is pointing to an int (which typically occupies 4 bytes), incrementing the pointer (ptr++) will move it by 4 bytes.

Example :
+++++++
int arr[] = {10, 20, 30, 40};
int *ptr = arr;

printf("Initial value: %d\n", *ptr); // Outputs 10
ptr++; // Increment pointer
printf("After ptr++: %d\n", *ptr); // Outputs 20 (pointer moves to the next element)
ptr--; // Decrement pointer
printf("After ptr--: %d\n", *ptr); // Outputs 10 (pointer moves back to the first element)


Note: When you increment or decrement a pointer, it doesn't just move 1 byte, it moves the size of the type it is pointing to. For example, for an int* pointer, it moves by sizeof(int) bytes, which is usually 4 bytes.


2.2. Pointer Arithmetic with Integer Addition/Subtraction (ptr + n, ptr - n)
------------------------------------------------------------------------------------------------------

You can also add or subtract an integer value to/from a pointer. The result of the operation is a new pointer that points to the new memory location, moving by n elements of the type the pointer is pointing to.

Addition (ptr + n): Moves the pointer n positions forward in memory (each position being the size of the type the pointer is pointing to).
Subtraction (ptr - n): Moves the pointer n positions backward.

Example :
++++++++

int arr[] = {10, 20, 30, 40};
int *ptr = arr;

printf("Initial value: %d\n", *ptr); // Outputs 10
ptr = ptr + 2; // Move pointer 2 positions forward
printf("After ptr + 2: %d\n", *ptr); // Outputs 30 (third element)

ptr = ptr - 1; // Move pointer 1 position backward
printf("After ptr - 1: %d\n", *ptr); // Outputs 20 (second element)

return 0;


Note: When adding an integer to a pointer, the pointer will move n elements, not bytes. So, adding 1 to an int* will move it by sizeof(int) bytes, which is usually 4 bytes.


2.3. Pointer Difference (ptr1 - ptr2) :

If you have two pointers pointing to elements of the same array, subtracting one pointer from the other will give you the number of elements between them. The result is an integer that represents how many elements are between the two memory addresses.

Example :
++++++++

int arr[] = {10, 20, 30, 40};
int *ptr1 = &arr[1]; // Points to second element (20)
int *ptr2 = &arr[3]; // Points to fourth element (40)

int diff = ptr2 - ptr1; // Difference in elements
printf("Difference between ptr2 and ptr1: %d\n", diff); // Outputs 2 (two elements between 20 and 40)

Note: The difference is based on the number of elements, not bytes. So ptr2 - ptr1 gives the number of elements between the two pointers.


2.4. Using Pointer Arithmetic with Arrays :

Pointer arithmetic is often used when dealing with arrays, as array names are pointers to the first element of the array.

For example, the following are equivalent:

arr[2] == *(arr + 2) // Accessing the 3rd element of an array


2.5. Caution with Pointer Arithmetic :

Out-of-Bounds Access: You should always be careful when performing pointer arithmetic, as going out of bounds can lead to undefined behavior, such as accessing memory that doesn't belong to the array.

Example:
++++++++

int arr[] = {10, 20, 30};
int *ptr = arr;
ptr = ptr + 4; // Pointer now points beyond the array bounds, undefined behavior

3. Pointers and Arrays in C :
======================

Arrays and pointers are closely related in C, and understanding how they work together is crucial for efficient memory management and manipulation.

3.1. Array Name as a Pointer :

In C, the name of an array is essentially a constant pointer to the first element of the array. For example, if you have:


Example :
++++++++
int arr[5] = {10, 20, 30, 40, 50};

The expression arr is a pointer to the first element arr[0]. However, this is not a modifiable pointer, meaning you cannot change the address of arr itself, but you can modify the elements it points to.


Example :
++++++++

int arr[3] = {10, 20, 30};
printf("arr = %p\n", arr); // Prints the address of the first element
printf("&arr[0] = %p\n", &arr[0]); // Prints the address of the first element
printf("*(arr) = %d\n", *arr); // Prints the value of the first element (10)

Output :
arr = 0x7ffee4a9d2c0
&arr[0] = 0x7ffee4a9d2c0
*(arr) = 10


3.2. Accessing Array Elements with Pointers :

Since arrays are pointers, you can access array elements using pointer arithmetic. For instance, arr[2] is equivalent to *(arr + 2).

Example :
+++++++

int arr[3] = {10, 20, 30};
int *ptr = arr;

printf("arr[2] = %d\n", arr[2]); // Access using array indexing
printf("*(ptr + 2) = %d\n", *(ptr + 2)); // Access using pointer arithmetic


3.3. Modifying Array Elements Using Pointers

You can modify array elements through pointers as well. Since arr is a pointer to the first element, you can use pointer arithmetic to change the value of any element.

Example :
++++++++

int arr[3] = {10, 20, 30};
int *ptr = arr;

*(ptr + 1) = 25; // Modify the second element using pointer
printf("arr[1] = %d\n", arr[1]); // Prints the modified value

Output :
+++++++
arr[1] = 25


3.4. Passing Arrays to Functions Using Pointers

When you pass an array to a function, you're essentially passing a pointer to the first element. Modifying array elements inside the function will affect the original array.

Example :
++++++++

#include <stdio.h>

void modifyArray(int *arr) {
arr[1] = 100; // Modify the second element
}

int main() {
int arr[3] = {10, 20, 30};
modifyArray(arr);
printf("arr[1] = %d\n", arr[1]); // Prints the modified value

return 0;
}


Output :
++++++
arr[1] = 100


3.5. Array of Pointers :

You can also have an array of pointers, where each element of the array is a pointer to a variable or an array.

Example :
++++++++

int x = 10, y = 20, z = 30;
  int *arr[3] = {&x, &y, &z}; // Array of pointers

for (int i = 0; i < 3; i++) {

    }

4. Pointer to Pointer in C :
======================

A pointer to pointer is a pointer that stores the address of another pointer. In other words, it points to the memory location of another pointer, which in turn points to a variable.

4.1. Syntax of Pointer to Pointer
----------------------------------------------------

type **pointer_name;


Example :
+++++++|
int x = 10;
int *ptr = &x;       // Pointer to an integer
int **ptr2 = &ptr;   // Pointer to pointer (pointer to ptr)


4.2. Dereferencing Pointer to Pointer
----------------------------------------------------------

To access the value of the variable x using a pointer to pointer, you need to dereference twice.

First dereference (*ptr2) will give you the address stored in ptr (which points to x).

Second dereference (**ptr2) will give you the value stored at the address ptr points to, which is x.

Example :
+++++++
int x = 10;
    int *ptr = &x;
    int **ptr2 = &ptr;

    printf("Value of x = %d\n", **ptr2);  // Dereferencing twice to access x

Output : 
++++++
Value of x = 10


4.3. Modifying Value Using Pointer to Pointer
-----------------------------------------------------------------------

Since a pointer to pointer ultimately points to the address of a variable, you can modify the value of the variable using pointer to pointer.

Example :
+++++++++
#include <stdio.h>

int main() {
    int x = 10;
    int *ptr = &x;
    int **ptr2 = &ptr;

    **ptr2 = 20;  // Modifying the value of x through pointer to pointer
    printf("Value of x = %d\n", x);

    return 0;
}

Output : 
Value of x = 20



4.4. Array of Pointers to Pointers :
++++++++++++++++++++++++++++

Just like arrays of pointers, you can have an array of pointers to pointers. This allows you to create more complex data structures like a 2D array using pointers.

Example :
++++++++

#include <stdio.h>

int main() {
    int x = 10, y = 20, z = 30;
    int *arr[3];  // Array of pointers
    int **ptr2 = arr;  // Pointer to pointer

    arr[0] = &x;
    arr[1] = &y;
    arr[2] = &z;

    for (int i = 0; i < 3; i++) {
        printf("Value = %d\n", **(ptr2 + i));  // Dereferencing pointer to pointer
    }

    return 0;
}

Output : 
------------
Value = 10
Value = 20
Value = 30


Explanation: ptr2 is a pointer to pointer, and arr is an array of pointers. You can access the values of x, y, and z through the array of pointers to pointers.

5. Function Pointers in C :
======================

A function pointer is a pointer that points to a function instead of a variable. It allows you to call a function indirectly and is useful for situations where you need to pass a function as an argument to another function, or when you need to decide which function to call at runtime.

5.1. Syntax of Function Pointers :
-----------------------------------------------------

Syntax : 
------------
return_type (*pointer_name)(parameter_types);


Example :
---------------
int add(int a, int b) {
    return a + b;
}

int (*func_ptr)(int, int) = add;  // Declare function pointer and assign it to 'add'


5.2. Calling a Function Using a Function Pointer :

Once a function pointer is assigned to a function, you can call the function using the pointer. You can call the function through the pointer using either:

Using dereferencing: (*func_ptr)(a, b);
Directly using the pointer: func_ptr(a, b);

Example : 

#include <stdio.h>

int add(int a, int b) {
    return a + b;
}

int main() {
    int (*func_ptr)(int, int) = add;  // Pointer to add function

    printf("Sum = %d\n", func_ptr(10, 20));  // Calling function through function pointer

}

Output : 
-----------
Sum = 30

6. Pointers to Structures :
=====================

A pointer to a structure is a pointer that points to a structure variable. It allows you to manipulate the contents of the structure indirectly using the pointer.

6.1. Declaring Pointers to Structure
-------------------------------------------------

To declare a pointer to a structure, you need to use the struct keyword followed by the structure type and then the pointer variable.

Syntax : 
----------
struct struct_name *pointer_name;

Example : 
---------------
struct Person {
    char name[50];
    int age;
};

struct Person *personPtr;


6.2. Accessing Structure Members Using Pointer :
-------------------------------------------------------------------------------

To access the members of a structure through a pointer, you need to use the -> operator. This is called the arrow operator.


-------------
pointer_name -> member_name

Example : 
-------------
#include <stdio.h>

struct Person {
    char name[50];
    int age;
};

int main() {
    struct Person person1 = {"Alice", 25};
    struct Person *personPtr = &person1;  // Pointer to structure

    // Accessing structure members using pointer
    printf("Name: %s\n", personPtr->name);
    printf("Age: %d\n", personPtr->age);
    printf("Name : %s\n", person1.name);
    printf("AGe : %s\n", person1.age);

    return 0;
}


6.3. Passing Structures to Functions Using Pointers
-----------------------------------------------------------------------------------

When you pass a structure to a function, it is passed by value by default, meaning a copy of the structure is passed. However, if you pass a pointer to a structure, the function can modify the original structure.


Example :
----------------
#include <stdio.h>

struct Person {
char name[50];
int age;
};

void updateAge(struct Person *personPtr) {
personPtr->age = 35; // Modify original structure
}

int main() {
struct Person person1 = {"Alice", 25};
struct Person *personPtr = &person1;

printf("Before: %s, Age: %d\n", personPtr->name, personPtr->age);

updateAge(personPtr); // Passing pointer to structure

printf("After: %s, Age: %d\n", personPtr->name, personPtr->age);

return 0;
}

Before: Alice, Age: 25
After: Alice, Age: 35`

Strings in C :
==========

In C, strings are treated as arrays of characters. A string in C is a sequence of characters terminated by a null character ('\0'). C does not have a built-in string type like some other languages, but it provides functions in the standard library to manipulate arrays of characters.

1. Declaring Strings :
--------------------------------
A string in C is declared as a character array. The string is terminated with the null character '\0' automatically when you initialize the array with a string literal.

char str[size];


Or, you can declare and initialize a string directly:

char str[] = "Hello";
char str[6] = "Hello";  // 5 characters + null terminator


In this example, str is an array of characters that can hold 6 characters: the 5 characters in "Hello" and the null terminator '\0'.


2. Initializing Strings :
-----------------------------------

c
char str[] = "Hello";
char str[6] = {'H', 'e', 'l', 'l', 'o', '\0'};
char str[10] = "Hello"; // Declare a string with more space than needed
char *str = "Hello";


3. String Representation in Memory :
---------------------------------------------------

A string in C is an array of characters, and each character in the string occupies one byte. The last character of a string is always the null terminator ('\0'), which indicates the end of the string.

Example:

char str[] = "Hello";

In memory, the string is stored as:

'H' 'e' 'l' 'l' 'o' '\0'

    strcpy(emp1.name, "Alice");
    emp1.salary = 75000.50;

    // Accessing structure members
    printf("Employee ID: %d\n", emp1.id);
    printf("Employee Name: %s\n", emp1.name);
    printf("Employee Salary: %.2f\n", emp1.salary);

    return 0;
}


NOTE : Members of a structure are stored in contiguous memory locations.

NOTE : You don't want to use new keyword to create object for struct as in java. just declare and assign value when you want.

2. Unions in C
----------------------

A union is similar to a structure, but with a key difference: all members share the same memory location. This means only one member can store a value at any given time.

Example : 

#include <stdio.h>

// Defining a union
union Data {
    int i;
    float f;
    char str[20];
};

int main() {
    // Declaring a union variable
    union Data data;

    // Assigning and accessing values
    data.i = 10;
    printf("Integer: %d\n", data.i);

    data.f = 3.14;
    printf("Float: %.2f\n", data.f);

    // Assigning and accessing string
    snprintf(data.str, sizeof(data.str), "Hello");
    printf("String: %s\n", data.str);

    return 0;
}


NOTE :
======
1. Use structures when you need to store and access multiple members simultaneously.
2. Use unions when you want to save memory and only one member is used at a time.


NOTE 2 :
======
In java, classes, Enums are user defined data types. Similarly in C, struct and union are user defined data types.

But In java, we use keywords 'class' and 'enum' only to define the data type. But in c, we use keywords 'struct' and 'union' for both definition and initialization(declaration).

This is the most confusing part. So be careful.


NOTE 3 :
=======
The size of a struct is combination of all the member variables of a struct.
But the size of union is the size of largest data type available in the union. All the variable of union use shared memory location.

Dynamic Memory Allocation in C :
============================

malloc() -> Allocates a block of memory but doesn’t initialize it.
calloc() -> Allocates and initalizes memory with 0.
realloc() -> Resizes a previously allocated memory block.
free() -> Frees the allocated memory and returns it to system.

NOTE :
-----------
malloc() and calloc() return a void * pointer, which needs to be cast to the appropriate type.

Example :
=========

int *arr = (int *)malloc(5 * sizeof(int));  // Allocate memory for 5 integers

int *arr1 = (int *)calloc(5, sizeof(int));  // Allocates and initializes to zero

arr = (int *)realloc(arr, 10 * sizeof(int)); // Resize the array to hold 5 integers

free(arr);  // Free the allocated memory


NOTES :
======
* Static Arrays are defined at compile time. They are stored in Stack.
* Dynamics arrays are created using malloc() and calloc(). They are stored in heap.

Difference Between Arrays and Pointers :
================================

1. Array :

# An array is a collection of elements stored in contiguous memory locations.

# The name of the array (arr) represents the address of the first element in most contexts, but it is not a pointer. It is a label for a block of memory.

# Its size is fixed and determined at compile-time (e.g., char arr[5] allocates 5 bytes for the array).


2. Pointer :

# A pointer is a variable that stores the address of another variable or memory location.

# The pointer itself has its own memory location and size (e.g., 4 bytes on 32-bit systems, 8 bytes on 64-bit systems).

# A pointer can point to different memory locations during runtime, but an array's base address is constant.
