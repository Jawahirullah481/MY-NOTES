Question 18 :
==========

Here we are using sizeof() on string literal instead of char array.

In C, string literals are also a char array but having '\0' at the end always.

Hence, if you use sizeof() on string, it will provide you length of array + 1('\0').

Output : 
======
7


Clarification Example :
=================
#include <stdio.h>

int main() {
    char arr[] = {'a', 'b', 'c'};
    char arr1[] = "abc";
    char arr2[5] = {'a', 'b', 'c'};
    char arr3[5] = "abc";
    
    printf("%d\n", sizeof(arr));       // Output : 3
    printf("%d\n", sizeof(arr1));      // Output : 4
    printf("%d\n", sizeof(arr2));      // Output : 5
    printf("%d\n", sizeof(arr3));      // Output : 5

    return 0;
}
