How to configure AOP in spring project :
=========================

1. Add dependencies(jar) :
======================
1. spring aop
2. aspectjrt
3. aspectjweaver


2. Add xml namespaces in beans tag.
======================
1. xmlns:aop="http://www.springframework.org/schema/aop"
2. xsi:schemaLocation="http://www.springframework.org/schema/aop
http://www.springframework.org/schema/aop/spring-aop-3.0.xsd "


3. Add tag for autoproxy :
=====================
<aop:aspectj-autoproxy />


4. Create bean tag for Aspect class
=============================
Example : <bean id="aspect" class="com.jawa.LoggingAspect"></bean>

SPRING 8 : AOP
Annotations for AOP :
==================

1. @Aspect
=========
This will be applied at class Level. Aspect is the class which contains lot of methods called advice.


2. @Before
=========
If you want a particular method(advice) to be called before specific method called, then you use @Before annotation

Syntax :
=======
@Before("pointcut expression")

Example :
========
@Before("execution(public void run())")
public void beforeRunMethod() {

}


3. @After
========
If you want a particular method(advice) to be called after specific method called, then you use @After annotation

Syntax :
=======
@After("pointcut expression")

Example :
========
@After("execution(public void run())")
public void afterRunMethod() {

}


4. @AfterReturning
================
Sometimes, inside the method, there may be exception rised. Because of that, the program doesn't reach the return statement. This annotation says "The specific advice method to be executed only after the return statement executed for method specified in pointcut expression". This has the flexibility to get the return value of the method.

Syntax :
======
@AfterReturning("pointcutexpression")
or
@AfterReturning(pointcut = "pointcutexpression", returning = "returnValueHolder")

Example :
========
@AfterReturning("execution(public void run())")
public void afterRunMethod() {

}

(or)

@AfterReturning(pointcut = "execution(public void run())", returning = "returnValue")
public void afterRunMethod(Object returnValue) {

}


5. @AfterThrowing
================
This is exactly similar to @AfterReturning. But, the only differentce is the advice method will be executed only if the specified method throws exception. This annotation says "The specific advice method to be executed only if the method specified in pointcut expression throw exception". This has the flexibility to get the exception reference thrown by the method.

Syntax :
======
@AfterThrowing("pointcutexpression")
or
@AfterReturning(pointcut = "pointcutexpression", throwing = "returnValueHolder")

Example :
========
@AfterThrowing("execution(public void run())")
public void afterRunMethod() {

}

(or)

@AfterThrowing(pointcut = "execution(public void run())", returning = "returnValue")
public void afterRunMethod(Exception returnValue) {

}


6. @Around
==========
This annotation will be executed "before and after" the execution of the method.
What are you saying? How is it possible?
Yes, This annotation has complete control over the execution of the method. you can stop the execution of the method inside this method.
Before, disucuss about that let's see syntax.

Syntax :
=======
@Around("poincut-expression")

Example :
========
@Around("execution(public void run())")
public Object aroundRunMethod(ProceedingJoinPoint pjp) {

      Code XXX;

      pjp.proceed();
   
      Code YYY;
}


Explanation :
==========
#. "Code XXX" will be called before run() called.
#. Then we are explicitly calling ProceedingJoinPoint.proceed(). Internally it calls run().
#. If we don't call ProceedingJoinPoint.proceed(), then run() won't be executed.
#. "Code YYY" will be called after run() executed.
#. If run method return value, then corresponding advice method for @Around should return value. Otherwise, it will throw exception.
#. If run method doesn't return value, then corresponding advice method for @Around need not return value.


7. @Pointcut
===========
If you want to execute multiple advice methods for single pointcut expression, then you don't need to specify same pointcut expression above all the advice method.
Rather you can use this @Pointcut annotation. For @Pointcut, we use dummy method.

Syntax :
======
@Pointcut("pointcut-expression")

Example :
========

@Before("runMethod()")
public void beforeRun() {

}

@After("runMethod()")
public void afterRun() {

}

@Pointcut("execution(public void run())")
public void runMethod() {}

execution(), within() and args() in pointcut expression :
===============================

1.execution :
==========

Syntax :
=======
@Annotation("execution(<method-signature>)")

As the syntax shows, if you provide method signature as pointcut, then use "execution".

Example :
========
@After("execution(public void run())")
or
@Before("execution(* run(..))")


2. within :
========

This is used when you register the advice for all methods in a class. Here, class is the value and not method.

Syntax :
======
@Annotation("within(<fully-qualified-name-of-class)")

Example :
========
@Before("within(com.jawa.Spring.Demo)")


3. args :
======

When you want to register advice method with respect to arguments of function.

Syntax :
=======
@Annotation("args(arg-name, arg-name)")

Example :
========
@Before("args(length,breadth)")
public void beforeArea(int length, int breadth) {

}

Note : if we use args, we can get arguments with same name in advice method. If argument name differ in advice method, then exception will thrown.
