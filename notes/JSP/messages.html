22:19
1. If custom tag invoked with attributes then jsp engine will automatically call corresponding setter methods to set attribute values.

2. If the tag is invoked with body then setJspBody() method will be automatically executed by taking JspFragment object as argument. JspFragment represents tag body in Simple Tag Model. In Simple Tag Model Tag body should not contain any scripting elements.

3. Finally Jsp engine executes doTag() method which is responsible to provide required functionality. This method is equivalent to doStartTag(),doEndTag() and doAfterBody() methods in classic tag model.

4. Once doTag() method completes ,the Tag Handler object will be destroyed by web container.

tld file tags :-
===========
1. taglib

2. tlib-version
3. uri -> any unique name

4. tag
4.1 name
4.2 tag-class
4.3 body-content
4.4 attribute
4.4.1 name
4.4.2 required
4.4.3 rtexprevalue

5. function
5.1 name
5.2 function-class
5.3 function-signature


Definition
========

1. taglib
This is the parent tag. It is the enclosing tag.

2. tlib-version
This tag tells the version of the tag.

3. uri
NOTE : It is "uri"(uniform resource identifier) not "url". So you have to give it a unique identifier name.

4. tag
Contains child tags.

4.1 name
Name of the tag

4.2 tag-class
Fully qualified name of the tag handler class for this tag.

4.3 body-content
Values are,
#. empty -> contains no body
#. tagdependent -> Total tag body is treated as plain text. Scriptlet, expressions are not processed.
#. scriptlet -> Tag may contains scriptlet, expressions and are processed.
#. jsp -> No restrictions on tag body. whatever allowed in JSP is by default allowed in tag body also.

4.4 attributes
Holds attribute information.

4.4.1 name
Name of the attribute

4.4.2 required
Is attribute mandatory

4.4.3 rtexprevalue
values are true/false. If true, runtime expression are allowed.

5. function
Used for custom function

5.1 function-name
name of the function.

5.2 class
Fully qualified name of the function.

5.3 function signature
<return type> <function name> (arguement list)

How to use custom function ?
#. If you want to create custom function, create class with public static method.
#. Compulsory, the method should be static.
#. configure tld file with above function tags.
#. add taglib directive with prefix
#. call function with prefix

Example :
========

Square.java
——————
public class Square{

public static int square(int i)
{
return i * i;
}

}


Squarefunction.tld
—————————
<taglib>
<tlib-version>1.0</tlib-version>
<uri>square<uri>
<function>
<name>square</name>
<function-class>com.package.Square<function-class>
<function-signature>int square(int i)
<function>
</taglib>

jspfile.jsp
========
<%@ taglib prefix="myfunc" uri="square" %>
<h1>${myfunc:square(5)</h1>
